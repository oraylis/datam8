# Security Reporting

Report sensitive vulnerabilities privately through
[GitHub's vulnerability-report route](https://github.com/oraylis/datam8/security/advisories/new).
Include affected component versions, reproduction and impact. If GitHub reporting
is unavailable, use the project contact DataM8@Oraylis.de.

This documentation describes v2 beta behavior; it does not establish a maintenance
or response-time guarantee. Maintainers must publish supported-release commitments
before a support policy is advertised. Do not post passwords, tokens or private
solution contents in public issues. See [secret handling](docs/security_guidelines.md).
