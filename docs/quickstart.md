# DataM8 Quickstart

Start with [installation](installation.md), then follow the
[illustrated user guide](user-guide/README.md). The first exercise opens a full
sample copy, edits Customer, verifies saving and generates local documentation.
It requires no Azure account or live database.

For automation development, use [templates and payloads](generator/README.md).
For tool development, use [repository responsibilities](repositories.md).
