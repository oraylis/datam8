# Secrets and Diagnostic Reports

Use the backend's supported secret-reference workflow. Keep plaintext credentials
out of solution JSON, screenshots and committed examples. Local browser examples
bind to loopback; desktop supplies an authentication token to its backend.

For connection exercises, use your own local fixture and disposable sample copy.
Do not contact example cloud hosts as part of routine checks. Generated code may
need separate deployment credentials; generation itself is not deployment.

Before sharing logs or screenshots, remove tokens, usernames, private hosts and
solution paths. Preserve useful error context and component versions. Publish
only reviewed capture assets; keep raw logs and transport evidence locally.

For vulnerability reporting, use [SECURITY.md](../SECURITY.md).
